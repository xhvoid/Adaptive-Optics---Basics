# Archived experiment notebooks

These are the original experiment notebooks from May–June 2026, kept as a
record of how the project developed. The maintained tutorials are one level
up, in `notebooks/`.

- `01`–`10`: the first experiment series. After the October 2026 fixes to
  the phase screens, frozen flow and edge slopes, all of them were re-run
  from a clean kernel, and the numbers in their text match their outputs.
- `minimal_sh_wfs`, `zernike`, `phase_screen`, `reconstruction`: the first
  standalone sketches. They carry their own inline code, including the
  original phase-screen generator, and are not maintained.

The numbered notebooks import the modules in `src/`, so run them after
`pip install -e .` from the repository root.
